# 从源码构建

运行预编译发行包不需要编译工具链。维护者构建需 Rust stable（支持 edition 2024）、Node.js 22+、npm 和 Linux 构建工具。

~~~bash
cd source/web
npm ci
npm run build
cd ../rust
cargo test --locked
cargo build --locked --release --bin vistart-controller
cargo build --locked --release --no-default-features --bin vistart-agent
~~~

主控编译时嵌入 dist-live，更新前端后必须重新编译主控。Agent 使用 --no-default-features，不包含数据库和管理界面依赖。

独立 MariaDB 测试使用 VISTART_TEST_CONFIG=/安全路径/qa-database.json cargo test --test compat。测试库名必须以 _qa 结尾，严禁使用生产数据库。

发布包含 amd64 / arm64 的 musl 静态二进制。交叉编译需安装对应 Rust target 和 C 工具链：

~~~bash
rustup target add x86_64-unknown-linux-musl aarch64-unknown-linux-musl
cargo build --locked --release --target x86_64-unknown-linux-musl --bin vistart-controller
cargo build --locked --release --target x86_64-unknown-linux-musl --no-default-features --bin vistart-agent
~~~

ARM64 构建应使用匹配的 musl 交叉编译环境。把主控放入 bin/controller-linux-{amd64,arm64}，Agent 作为发布资产而不提交大型二进制到 Git 历史。

ops/package-release.py 创建安装包、签名清单和 Agent 清单。签名私钥必须在仓库外、仅 root 可读，且公钥匹配内置发布信任根。公开仓库不包含私钥、真实状态、数据库、测试凭据或 SSH 信息。

检查包括 cargo clippy --all-targets -- -D warnings、cargo audit、npm audit、shellcheck、Python 语法检查，以及真实 WSS / TCP / UDP / 计费 / 订单 / 浏览器回归。
