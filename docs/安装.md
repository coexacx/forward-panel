# 安装与管理

## 1. 准备

一台有 root 权限、systemd 和外网连接的 Linux 服务器。建议主控至少 1 核、512 MiB 可用内存、1 GiB 磁盘；MariaDB 与系统开销另计，正式部署建议 1 GiB 以上内存。支持 amd64 / arm64。

安装器覆盖 Debian 12/13、Ubuntu 22.04/24.04/26.04、Rocky / AlmaLinux 9/10、CentOS Stream 9/10、Fedora 42/43/44。完整安装实测环境见验收文档；发行版适配不表示全部组合均有实机测试。

安装器遇到已有非 MariaDB 数据库或无法管理的数据库实例会停止，不自动替换现有 MySQL。宝塔已有数据库的服务器请使用手动部署和独立 MariaDB。

## 2. 安装

~~~bash
curl -fL https://github.com/coexacx/forward-panel/releases/latest/download/install.sh -o /tmp/forward-panel-install.sh
bash /tmp/forward-panel-install.sh
~~~

输入站点名称。脚本自动安装 MariaDB、证书根、下载与管理工具，验证发行包并创建专属数据库。默认端口 19280；若被占用可用 --port 其他端口。无交互安装支持 --site-name '我的面板'。

安装完成显示访问地址、管理员用户名及随机初始密码。凭据保存在 /etc/forward-panel/initial-admin.json，仅 root 可读。登录后及时修改密码并启用二步验证。

若存在云安全组或防火墙，请自行开放需要的入口；脚本不修改整机防火墙。MariaDB 只需本机访问，不开放到互联网。

## 3. 正式域名

自行解析域名、配置 Nginx 和有效证书，按[反向代理文档](反向代理.md)操作。然后执行 forward-panel，选择“设置访问地址”，填入 https://你的域名。

使用 HTTPS 地址后主控改为只监听 127.0.0.1，公网通过 Nginx 访问。未配置 HTTPS 时不能部署 WSS Agent。

## 4. 菜单

sudo forward-panel 打开维护菜单。提供更新、重启、启动、停止、日志、状态、访问地址、备份、重置管理员密码、文档、回退、卸载。

更新由管理员确认后执行，校验签名并在切换前备份数据库与私有状态。健康检查失败自动恢复旧程序与数据。更新会短暂重启主控，建议低峰期执行。

“回退上个版本”恢复上一版本及升级前数据库，需要输入 ROLLBACK。更新之后的新业务数据会被回退覆盖，应先备份当前数据。

备份保存在 /var/backups/forward-panel，只有 root 可读。卸载仅删除面板程序与服务，保留数据库、状态和备份；不会删除转发节点上的其他应用。

## 5. 目录

| 路径 | 用途 |
| --- | --- |
| /opt/forward-panel | 程序、管理脚本、文档 |
| /var/lib/forward-panel | 数据库连接、加密密钥、任务与 SSH 指纹 |
| /etc/forward-panel | root 管理配置及初始凭据 |
| /var/backups/forward-panel | 备份 |
| /var/lib/forward-panel-updater | 上一版本与升级前快照 |
| forward-panel.service | 主控服务 |

面板状态目录必须私有，不得作为静态网站根目录。程序的 state 是指向私有状态目录的链接。
