# 0.3.5 验收记录

日期：2026-10-09。开发、编译、功能与负载测试在开发服务器和独立测试节点完成。以下记录只代表已执行的检查，不代表不存在漏洞。

## 用户套餐流量调整

管理员可在用户套餐的“管理套餐”中选择“修改已用流量”，设置当前周期已用总量。后续节点上报只增加新的用量，原始累计游标及去重序号不变。到期日、自然重置日、套餐限额、付款订单与手动暂停状态不变，操作日志与修改在同一事务内提交。

在测试站实际创建用户、两份套餐和两条 TCP+UDP 规则，通过 HTTPS 网页、主控 WSS 与测试节点进行验证：

- 普通用户越权、无效 CSRF、负数、小数、越界值、非法数值和过期周期请求均被拒绝；整数格式字符串按现有 API 约定安全转换。
- 浏览器将已用流量改为 2 MB，持续 TCP 连接的 22 次应答全部成功，修改前后的连接保持工作。MB / GB / TB 与面板显示一致，按 1000 进位。
- 随后通过同一连接上传、下载合计 524,288 字节，新用量从 2 MB 继续累计，其他套餐没有变化。
- 调高到超额时关闭该套餐连接，另一套餐继续转发。调低后等待 Agent 新确认，再建立连接验证恢复成功。
- 手动暂停期间调整流量不会解除暂停；到期日和自然重置日保持不变。
- 桌面和手机浏览器完成操作、表单显示与审计日志检查，无 JavaScript 异常、HTTP 5xx 或整页横向溢出。

实测还发现恢复规则可能短暂沿用暂停前的监听确认。现按受影响租约记录所需配置版本，收到新的 Agent 确认后才显示已监听；其他租约不会重新显示下发中。低于额度的普通用量修改不重新下发原规则。

## 自动回归与构建

21 项 Rust 测试全部通过：11 项单元测试、5 项 MariaDB / 业务集成测试和 5 项真实回环网络测试。覆盖跨节点累计上报去重、调整后继续计量、计费周期变化、权限、共享额度、规则迁移、TCP 半关闭、UDP、增量规则变更、连接统计及资源预算。

Clippy 全目标警告检查、Rust 格式检查、TypeScript 与前端生产构建通过。amd64 主控与 Agent 已在真实测试环境运行；arm64 完成交叉编译和 ELF 架构检查，未进行独立 ARM 硬件验收。

0.3.5 没有更改 Agent 转发数据路径，保留 0.3.4 的 socket 内存保护。OOM 复现对照、吞吐结果及高时延单连接的限制见 [0.3.4 验收](验收-0.3.4.md)，本次未重复进行相同内核基准测试。

## 安全与请求压力

私有文件路径、路径穿越、Host、请求体/头/URI 大小边界、匿名越权、登录限速、WSS 认证及跨站拒绝、慢请求头超时均通过。人工审阅了管理员权限复核、事务边界、累计计量游标、整数计算、审计记录与配置确认范围。

200 个并发客户端请求管理接口 600 次，耗时 1.569 秒，128 次正常返回、472 次触发 429 限流，P95 1367.36 ms，没有 5xx 或进程崩溃。429 是主动限流，不计为成功业务吞吐；这项快速检查不是独占硬件性能基准。

npm 审计 0 项已知漏洞。RustSec 在线更新到提交 7eebec69c352c7191b1f13eb95dd510eeca5d1de，仍有 RUSTSEC-2023-0071，涉及 rsa 0.9.10 与 0.10.0-rc.18，没有新增依赖或新增告警。实际使用路径见 [SECURITY.md](../SECURITY.md)，不将结果描述为零告警。

源码与解压发行包执行凭据扫描；压缩包校验全部文件 SHA-256、路径、权限与内容边界，面板和 Agent 下载清单验证 Ed25519 签名。真实数据库、站点配置、SSH 密码和验收凭据不进入源码包。

## 升级边界

升级不改变数据库结构、已有规则、套餐或计费周期。首次使用本功能时，管理员对具体套餐明确提交新用量才会修改计量值。主控与 Agent 升级需要服务重启，产生一次计划内的短暂中断。安装和反向代理方式不变。

使用方法见 [已用流量调整](已用流量调整.md)。0.3.4 之前的连接统计与限额验收记录继续保留。
