# 每条规则的实时连接数

从 0.3.3 起，「我的转发」与管理员「全部转发」为每条规则显示 TCP / UDP 当前数量。主控和 Agent 均需升级至 0.3.3。

- **TCP**：已成功连接目标、尚未结束的转发连接。等待套餐额度或目标连接失败不计入，TCP 目标探测也不计入。
- **UDP**：该规则中当前存在的客户端来源地址与端口会话。相同来源的多个数据包只计一次；连续 30 秒无双向流量后回收。UDP 数量不代表目标已确认可用。
- 多目标负载均衡显示整条规则的合计；套餐连接限额仍按同一已购套餐跨节点执行。
- Agent 沿用 WSS 认证链路每秒上报，页面约每 3 秒刷新。统计是最近上报的快照，不是累计连接次数或连接上限。
- 离线、上报超时、旧 Agent 未提供统计时显示「—」。有新数据且当前无连接时才显示「0」。浏览器无法刷新超过 15 秒也会停止显示旧数字。
- 更换计费周期或调整额度时，仍在传输的连接继续计数。删除、改目标或暂停使原连接退出后，计数随实际状态变化。
- 用户只看到自己规则的统计，共享节点的原始规则统计不会出现在用户收到的节点探针数据中。

统计沿用现有探针 JSON 存储，无数据库结构迁移。计数仅在 TCP 连接或 UDP 会话开始、结束时变化；没有新增逐包计数、端口扫描或额外页面轮询。
