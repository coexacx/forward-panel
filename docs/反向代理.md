# Nginx 与 HTTPS 反向代理

安装脚本只安装主控和数据库。Nginx、域名解析、证书申请与续期由站点管理员配置。

下面以 panel.example.com、主控端口 19280 为例。域名先解析到主控服务器，证书必须匹配域名并包含完整证书链。修改后使用实际 Nginx 路径运行 nginx -t，通过后再 reload。

## 完整虚拟主机示例

~~~nginx
server {
    listen 80;
    server_name panel.example.com;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    server_name panel.example.com;
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    autoindex off;
    client_max_body_size 64k;
    client_header_timeout 10s;
    client_body_timeout 10s;
    send_timeout 60s;
    keepalive_timeout 30s;

    location ~ ^/api/admin/(preview-rules|import-rules)$ {
        client_max_body_size 8m;
        proxy_pass http://127.0.0.1:19280;
        proxy_http_version 1.1;
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";
        proxy_request_buffering off;
        proxy_buffering off;
        proxy_connect_timeout 5s;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
    }

    location / {
        proxy_pass http://127.0.0.1:19280;
        proxy_http_version 1.1;
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_connect_timeout 5s;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
        proxy_buffering off;
    }
}
~~~

主控 API、页面、支付回调、Agent WebSocket 均通过同一个入口。不使用 PHP location，不配置 try_files 回退到 PHP。

## 宝塔

1. 宝塔创建 PHP 版本选择“纯静态”的站点，绑定域名。
2. 在 SSL 页面申请或导入有效证书，启用 HTTPS。
3. 打开站点“配置文件”。在现有 HTTPS server 内放置上面的通用限制与 location /；保留宝塔的证书路径、日志和证书验证配置。
4. 如果“伪静态”文件已经包含 location /，删除重复配置。也可把 location / 单独放进伪静态文件，但 autoindex / client_* / send_timeout 等写在 server 内。一个请求路径只能有一份对应 location。
5. 删除此站点的 PHP include，不要删除其他站点的 PHP 配置。
6. 检查配置后重载 Nginx。
7. 运行 forward-panel，选择 7，填写 HTTPS 域名及原服务端口。

代理由同一台服务器的回环地址连接。主控 HTTPS 模式必须绑定 127.0.0.1，确保外部不能直接伪造代理头。反向代理在另一台服务器的场景需另行设计受限网络及认证，不适用此模板。

## 验证

浏览器打开 HTTPS 地址并登录，后台添加测试节点，确认显示在线与 Agent / 内核版本。节点持续 WSS 上报，Nginx 应返回 WebSocket 101。主控日志不得出现重复认证失败。

如果使用 CDN，确认支持 WebSocket。不要直接信任访客提供的 X-Forwarded-For；只有在 Nginx 正确配置 CDN IP 白名单后才使用经校验的客户端地址。

运行中且已有节点的域名变更不能直接通过首次配置菜单操作，见[迁移](迁移.md)。

0.3.1 的规则导入仅为上述两个管理员路径开放 8 MiB 请求上限，并关闭请求缓冲；其余 API 仍由主控限制为 64 KiB。升级已有站点时补充这段 location，避免较多规则的文件被 Nginx 提前返回 413。
