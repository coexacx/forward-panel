# 套餐限额与强制变更预览

适用于 0.3.2 及以上的主控与 Agent。

## 限额口径

在后台“套餐管理 → 添加 / 编辑套餐”设置：

| 字段 | 单位和含义 |
| --- | --- |
| 总带宽 | Mbps（1 Mbps = 125000 字节/秒），上行与下行合计 |
| TCP 连接上限 | 同时建立的转发 TCP 连接数量 |
| UDP 会话上限 | 活跃 UDP 转发会话数量；同一规则下按客户端 IP 与源端口识别 |

以上均为同一份已购套餐在所有节点、所有转发端口上的合计上限。不同已购套餐独立计算，TCP 与 UDP 分别计数。填 0 表示该项不限，仍受节点自身的安全容量和物理资源约束。升级不会自动为已有套餐添加限制。

UDP 会话连续空闲 30 秒后释放。TCP 连接数不是设备数、账号数或代理协议内部的逻辑请求数。

## 执行方式

主控为每份租约协调各节点的可用带宽与连接容量，Agent 在本机执行。控制连接只传递配置、额度与统计，业务流量不经过主控。

- 同一节点上的同套餐规则共享一个限速器和连接计数。
- TCP 通过异步等待控制发送速度，避免忙等。UDP 超出当前带宽或会话额度时丢弃数据报，避免无界排队。
- TCP 额度暂不可用时短暂等待，等待人数和时间均有限制；不会无限积累待处理连接。
- 减少某节点的额度后，主控收到对应确认才把释放的容量给其他节点。
- 额度预留写入数据库；主控重启、节点重连时不会把未到期预留重复分配。异常断线后的预留最多保留约 30 秒，期间可暂时降低可用容量。
- 带宽为应用转发载荷的速率控制，允许令牌桶突发，并非网卡线路整形；不包括 TCP/IP 封装等链路开销。
- 每个节点的突发容量约为其分配速率的 100 毫秒，最少 65535 字节以容纳完整 UDP 数据报，最多 1 MiB；多节点突发量会合计，低速套餐不保证每个瞬间都低于设定值。
- 降低连接上限时，已有连接继续至关闭；超额期间不接纳新的连接。删除规则、移除节点或套餐暂停仍会终止对应转发。
- 旧 Agent 无法执行新限额。主控会停止向旧 Agent 下发带限额的规则，页面提示升级；不限额规则保持兼容。

## 同步已购套餐

普通保存只修改套餐商品，已有租约保留购买时的设置。

如需将新带宽、连接数、端口、流量、节点或后续周期同步给已购买用户：

1. 勾选“强制更新已有用户套餐”并保存。
2. 查看涉及的用户与租约、各项额度的前后变化、将释放的具体转发，以及流量暂停或恢复的影响。
3. 核对后勾选确认，再点击“确认更新”。
4. 面板在事务中重新计算影响，通过后统一保存并下发。

预览不修改数据，凭证有效 5 分钟。套餐、规则或实际暂停结果发生变化时，旧确认会被拒绝，需要重新预览。持续上报的流量只在改变暂停/恢复结果时使预览失效，避免正常使用期间无法确认。

强制同步保留已用流量、当前到期日、自然重置日与当前计费周期。缩减端口数量时优先保留较小端口；移出允许节点的规则会被释放。已结束或已删除的租约不会重新启用。
