# 服务器维护与规则迁移

适用于 0.3.1 及以上的 Rust 主控和 Agent。主控不承担业务转发。

## 编辑服务器与更新 Agent

在“转发服务器”中：

1. **编辑**：修改名称、地区、启用状态和对外显示连接 IP。显示 IP 可为 NAT 或互联入口，保存后同步端口池与已有转发的展示地址；它不决定内核绑定哪张本机网卡。
2. **连接信息**：填写 SSH IP、端口、用户名、密码并验证保存。密码加密存储，后续留空会保留原密码；更改 SSH 地址、端口或用户名必须重新填写。
3. **更新**：面板自动检查签名发行清单；仅检测到比节点当前版本更新的稳定版本并已保存连接信息时可点击。检查失败会显示不可用，不会假称已是最新版。可点击“检查更新”重试，手动检查间隔至少 30 秒，页面开启时每小时自动检查。
4. 更新会下载并验证签名、哈希和大小，保留节点身份、端口和累计流量。成功任务保留约 5 秒后自动从任务列表清理，失败任务保留供排查。

升级 Agent 会短暂重启其转发服务。正常新增、修改或释放规则使用增量同步，不会重启无关规则的监听或已有连接。旧 Agent 仍可接收全量配置，但新状态确认与增量同步需要升级 Agent。

## 即将到期或维护的服务器迁移

1. 在旧服务器的“详情 → 规则导入 / 导出”下载 JSON 文件。
2. 添加并部署新服务器，确认 WSS 在线，保存 SSH 连接信息，并配置允许分配的端口池。
3. 在新服务器的“详情 → 规则导入 / 导出”选择刚才的文件。
4. 查看预览：原入口、新入口、目标、受影响套餐。原端口在新端口池内且未占用时优先沿用；否则选择池内可用端口。没有足够端口时不修改原规则。
5. 确认导入。面板更新规则及有关套餐的节点绑定，撤销旧入口并下发新入口。跨服务器迁移会断开旧入口上的现有连接。
6. 在“全部转发”检查“节点已监听”和目标连通状态。用户的“我的转发”会自动刷新为新服务器、显示 IP 与最终端口，不需要用户再次创建。

保留用户、租约、转发目标、负载均衡目标、备注、端口额度、已用流量、到期时间和自然重置日。流量超限、暂停或到期状态仍有效。删除旧节点曾使套餐自动暂停时，恢复后需管理员核对并恢复套餐；不会擅自绕过暂停。

原规则、目标端口占用或套餐绑定在预览后变化时，需要重新预览。确认凭证有效 5 分钟。已迁移的规则不能通过旧文件重复导入，应从当前承载规则的服务器重新导出。

## 同一台服务器重装系统

推荐保留主控中的服务器记录：

1. 重装前导出规则作为备份，保留主控记录。
2. 重装 Debian 或 Ubuntu。
3. 在原节点“连接信息”更新 SSH 密码，勾选“系统已重装，保存后重新部署 Agent”。
4. 若主机指纹变化，页面显示旧、新指纹；核对后确认继续。后台自动更新不会静默忽略指纹变化。
5. 部署恢复原节点身份，自动取回面板配置。若本机网卡地址变化，更新原自动检测网卡对应的端口池与规则绑定。
6. 如需从文件核对恢复，在原节点导入规则。相同节点保留原规则编号，不重复占用端口额度。

也可添加为新节点，再使用迁移流程。旧节点记录已删除时，签名文件仍可关联保留的租约和计费记录进行恢复，但套餐必须仍存在、未结束且端口额度足够。

## 文件与计费

规则文件只用于本面板的规则迁移，不是整个面板的灾难恢复备份；它不包含账户密码、SSH 密码、Agent 凭据和支付密钥。不要编辑 JSON 内容，否则签名校验失败。面板迁移或灾难恢复仍需备份 MariaDB 与完整 state，尤其是 app.key。

删除套餐商品保留已购买租约；管理员删除租约则停止其转发并释放端口。用户只能删除自己的结束或到期租约。订单和小型计费记录保留，避免迟到报告、支付回调或重试导致丢账或重复开通。

强制同步套餐会更新名称、额度、节点和后续周期，保留已用流量、当前到期日及下次重置日。减少节点或端口额度会释放不再允许的规则，优先保留较小端口。
