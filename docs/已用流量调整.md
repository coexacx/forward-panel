# 管理员调整用户套餐已用流量

进入 **后台 → 用户套餐 → 管理套餐 → 修改已用流量**。填写新的已用总量，选择 B、MB、GB 或 TB，然后保存。也可从用户管理中的套餐租约详情进入。

MB / GB / TB 与面板流量显示一致，按 1000 进位，输入数值按最接近的字节取整。这里只修改当前套餐、当前流量周期的计量值，套餐到期日、自然重置日、额度、付款订单与价格不变。不是给用户提供免费重置入口；普通用户调用接口会被拒绝。

后续所有所属节点上报的新增流量继续累加到新数值。Agent 原始累计游标与去重序号保留，重复或迟到的已确认累计值不会把总量改回旧值。尚未上报的在途用量仍在收到报告时计入。

达到或超过套餐额度时，该套餐在所有节点的转发暂停。调低后，仍有效且没有手动暂停、账户停用等限制的转发恢复。已结束或已到期套餐不能调整；自然重置发生或计费周期变化后，需刷新套餐详情再修改。

总量按调整前的上传、下载占比分配到本期计量值；原用量为零时计入下载部分。原始节点累计日志不变。操作日志记录管理员、用户、套餐、原总量、新总量和计费周期，并与修改在同一个数据库事务中提交。

支持设置为零；最大可编辑值为 9,007,199,254,740,991 字节，避免浏览器整数精度丢失。修改为零不会延长到期日或改变后续自然重置规则。

此功能与 0.3.4 的 socket 内存保护同时保留。调整后若仍低于额度，规则内容不变，现有连接继续工作；超过额度触发暂停时会正常关闭连接。

暂停后恢复时，仅该套餐的规则等待对应节点的新配置确认，避免短暂沿用旧的监听确认；其他套餐的规则保持原状态。
