# 0.3.0 验收记录

验证日期：2026-10-05。以下为本次实测范围与结果，不能代替未来版本的回归测试或独立渗透测试。

## 功能

- Rust 单元、MariaDB 兼容集成与真实网络测试通过：4 个单元测试、1 个包含多业务场景的数据库集成测试、2 个网络测试；Clippy 全目标检查无警告。
- 保留旧版密码散列和加密配置，测试角色隔离、CSRF、会话撤销、目标与端口归属、不同用户数据隔离。
- 真正连接 Debian 测试节点，测试 TCP 半关闭、UDP 零字节/常用长度/MTU 数据报、TCP 与 UDP 多目标负载均衡。
- 检查 TCP+UDP 占一个端口额度、端口池与租约限额、累计流量及去重、64 KiB 测试额度触发实际停止转发；重置后恢复、续费保持流量、重置不改变到期日。
- 验证目标备注、持续 TCP 探活，二步验证二维码/密钥、重放拒绝、恢复码单次使用及关闭。
- 验证本地 SMTP 收信、验证码 60 秒限制、错误验证码、密码找回与单次令牌；支付使用合成签名回调，验证付款方式、金额篡改拒绝、重复回调幂等、手动支付/取消。测试未向真实商户发起扣款。
- 在线删除节点下发清理；离线删除后重新添加会纠正旧的同面板 Agent 配置。测试服务器原有探针服务保持正常。
- 管理员与用户界面共 40 个桌面/手机页面检查通过，无脚本异常、HTTP 5xx 或横向溢出；首次 HTTP 安装实例另测 40 个页面。
- 签名发行包新装、备份、更新、更新失败自动恢复、手动回退数据库及私有状态通过。应用密钥、SSH 指纹及状态目录 0700 权限保持。
- amd64、arm64 静态二进制均构建；本次真实运行和性能测试使用 amd64，arm64 尚未完成独立服务器验收。

## 安全与负载

私有路径、路径穿越、Host 限制、请求体/请求头/URI 大小、匿名越权、登录限速、WSS 认证与跨站拒绝、慢请求头超时均验证。SPA 路由始终只返回内嵌页面，不读取 URL 指向的磁盘文件。

200 个并发客户端向管理状态接口发起 600 次请求，0.822 秒完成：130 次 HTTP 200、470 次 HTTP 429，无 5xx 或崩溃。P95 为 643 毫秒。大部分请求触发保护限流，因此 730 次/秒是包含拒绝请求的响应速率，不是成功业务吞吐量。

前端 npm 全依赖审计为 0 项已知漏洞。Rust 依赖仍报告 RUSTSEC-2023-0071，涉及 SQLx/Russh 引入的 rsa 0.9.10 与 0.10.0-rc.18；适用路径说明见 SECURITY.md。未将该提示隐藏或宣称零漏洞。

源码与解压发行包使用 Gitleaks 检查；签名公钥及校验和为公开验证材料，校验和误报只有在逐文件验证后才排除。发布不含数据库、站点状态、管理员密码、节点凭据或签名私钥。

## 转发内核比较

同一开发主机，Go 1.27.1 与 Rust 1.98.1 的发布构建；只测相同转发引擎，未计入完整 Agent 的 WSS 和探针采集开销。引擎固定到一个 CPU 核，客户端和服务端各使用另外一个 CPU 核，经回环地址压测；每项两次、每次 8 秒并忽略首秒。下表速率/CPU/丢包为两次均值，RSS 为两次最大值。该数据不是跨机公网带宽或长期稳定性保证。

| 内核 | 场景 | 接收 Mbps | 单核 CPU % | 峰值 RSS MiB | UDP 丢包 |
|---|---|---:|---:|---:|---:|
| go | tcp-1 | 6739.44 | 98.5 | 15.26 | 0% |
| rust | tcp-1 | 11667.79 | 99.02 | 1.35 | 0% |
| go | tcp-16 | 6932.76 | 98.12 | 15.45 | 0% |
| rust | tcp-16 | 10864.58 | 98.36 | 2.04 | 0% |
| go | tcp-16-reverse | 6663.64 | 97.95 | 15.48 | 0% |
| rust | tcp-16-reverse | 10563.51 | 98.5 | 2.03 | 0% |
| go | udp-200M | 199.9 | 51.92 | 13.31 | 0.043% |
| rust | udp-200M | 199.4 | 30.55 | 1.47 | 0.299% |
| go | udp-600M | 549.01 | 87.58 | 15.27 | 8.466% |
| rust | udp-600M | 596.19 | 62.7 | 1.46 | 0.63% |

TCP 单连接约提升 73%，16 连接约提升 57%。UDP 600 Mbps 测试中 Rust 接收约 596 Mbps，平均单核 CPU 约 63%；200 Mbps 场景两次丢包有波动，不能据此断言所有场景都没有丢包。共享主机调度与本机 UDP 缓冲会影响结果。

测试中修复了 UDP 突发接收队列过小的问题，扩大到每客户端 128 个待发送包，同时保留全局 8 MiB 载荷上限。增加 64 包突发及精确计费回归测试。历史流量日志超过 4096 项后只压缩已确认且不再使用的记录，保留待确认增量；并发计数与重启恢复已测试。

长时间公网运行、非 amd64 机器和不同发行版的行为仍需持续观察。
