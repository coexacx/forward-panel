# 0.3.4 验收记录

日期：2026-10-09。所有开发、构建和负载测试在开发服务器与独立测试节点完成；生产只做备份、更新和低负载回归。本记录仅描述已执行的检查，不代表不存在漏洞或可以保证永不中断。

## 故障与修复

生产内核日志确认：Agent 的固定 128 MiB systemd 内存限额被触发，其中约 122 MiB 来自 TCP socket 内核缓冲。内核终止 Agent 后，服务自动重启并向主控重新获取规则，页面因此出现重新下发。RSS 较小并不能排除这类问题。

主控部署器按节点物理内存四分之一生成 64 MiB–2 GiB 的服务上限；Agent 读取可见 cgroup 层级限制，在接受新连接前预留 socket 与应用缓冲。缓冲大小与剩余预算相关，不修改主机全局网络参数。预算不足拒绝新增连接，保留仍在工作的连接。详见 [Agent 资源保护](Agent资源保护.md)。

正常 TCP 半关闭在数据被确认后回收预留；错误或取消及时清理内核队列。既有读写停滞保护、流量达量、套餐到期及失联保护不变。

## 复现对照

相同开发机、相同回环目标、相同 128 MiB cgroup 上限，旧版与新版使用相同测试驱动。每轮 96 个慢速连接，三轮分别模拟慢速下载、上传目标不读取、再次慢速下载；同时维护原有应答连接，每秒重复刷新相同配置。

| 结果 | 0.3.3 | 0.3.4 |
| --- | ---: | ---: |
| cgroup 观测峰值 | 157.11 MiB | 17.08 MiB |
| 进程结果 | OOM 终止 | 保持运行 |
| 持续连接成功应答 | 0 | 150 |
| 持续连接错误 | 2 | 0 |
| PID 保持不变 | 否 | 是 |

内核并发分配时观测峰值可以短暂超过硬上限。新版测试历时 23.53 秒，原有连接最长单次应答 4.11 ms。部分新连接会按资源预算拒绝；这项结果不是无限接纳全部连接的承诺。此为快速复现对照，未用它替代长期稳定性测试。

## 吞吐边界

回环 iperf3 检查将转发引擎固定到一个逻辑核，收发端使用另外两个核，不与编译并行。16 路 TCP 短测旧版约 10.02 Gbit/s，新版约 10.33 Gbit/s；反向分别约 7.51 / 8.10 Gbit/s。

单连接追加三轮 10 秒测量：旧版范围 7.93–9.46 Gbit/s，中位数 8.25；新版范围 6.62–10.95 Gbit/s，中位数 7.15。本组新版中位数下降约 13.4%，波动较大，不能据此声称全面更快。限制 socket 缓冲也可能影响高时延单连接吞吐，需结合实际链路带宽与内存预算评估。

UDP 复测在 200 / 600 Mbit/s 发送率下，新版接收约 199.44 / 596.98 Mbit/s，丢包率约 0.276% / 0.496%；旧版约 199.99 / 598.95 Mbit/s，丢包率约 0.001% / 0.168%。这是共享虚拟机的快速性能检查，不代表生产公网、所有时延条件或长期满载成绩。

## 安全与请求压力

私有文件路径、路径穿越、Host、请求体/头/URI 大小边界、匿名越权、密码登录限速、WSS 认证及跨站拒绝、慢请求头超时均通过。人工审阅预算申请与回收、取消路径、正常半关闭、socket ioctl 生命周期以及日志敏感信息处理。

200 个并发客户端请求管理接口 600 次，耗时 1.145 秒，响应分布 {"200": 128, "429": 472}，P95 935.91 ms，没有 5xx 或服务崩溃。429 为主动限流，不计作成功业务吞吐；这项检查不作为独占硬件吞吐基准。

npm 审计 0 项已知漏洞。RustSec 数据库提交 550efd3d587a29b2e2c2b21b17a440da4fede999，仍有 RUSTSEC-2023-0071，涉及 rsa 0.9.10 与 0.10.0-rc.18，本次没有新增依赖或依赖告警。使用路径和限制见 [SECURITY.md](../SECURITY.md)。源码和解压发行包另做凭据扫描。

## 发布范围

提供 amd64 / arm64 静态主控与 Agent。实机使用 amd64；arm64 仅交叉编译、ELF 架构和发行完整性检查，未进行独立 ARM 硬件验收。发布校验 SHA-256、Ed25519 清单、压缩包路径与权限，真实数据库、配置、密钥和验收凭据不进入源码包。

升级不改变数据库结构、现有规则、套餐或计费周期。主控升级和 Agent 更新需要服务重启，会产生一次计划内的短暂中断。安装和反向代理方式不变。此前连接统计验收见 [0.3.3 记录](验收-0.3.3.md)。
