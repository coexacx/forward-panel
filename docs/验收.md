# 0.3.8 验收记录

日期：2026-10-10。开发、构建和主动故障测试在开发服务器与独立测试节点完成；生产仅做低负载诊断、备份及受控更新。

## 长连接

TCP 空闲判定从“两个方向分别计时”更正为“同一连接共享双向活动记录”。不增加独立任务或定时业务轮询，保留真正空闲 300 秒、写入阻塞、主控授权、套餐限额和资源保护策略。

共享空闲截止时间单元测试通过：一个方向持续接收数据时，另一方向的读取继续等待；两边停止活动后，读取按空闲规则结束。

Debian 测试节点以普通 Agent 账户运行编译后的 amd64 musl 静态测试二进制，在独立回环网络中同时建立两条转发，分别持续上传和下载。运行 330.09 秒，安静方向不发送额外应用保活消息，两条连接均跨过 300 秒截止点，全部数据完整。结束后规则连接数与套餐额度归零，累计流量逐字节校验通过。

## 回归与回收

常规套件 28 项通过：13 项单元、6 项 MariaDB / 业务集成和 9 项回环网络测试。另在 Debian 静态二进制上显式执行双网卡与长连接测试，合计实际覆盖 30 项不同测试。

独立双网卡环境中 10 项网络回归通过，包括 TCP/UDP 配对绑定、指定网卡 UDP 回复源地址、半关闭、慢速读取、增量规则、流量计量、UDP 空闲、12 条规则共享套餐额度、删除后端口复用，以及单侧 / 双侧 EOF 后复位。长连接测试在另一独立网络中执行，均未更改现有节点的接口或路由。

最终代码再次执行客户端、目标端各 1,000 次复位，共 2,000 轮；逐轮验证连接计数及套餐额度归零，再验证可重新连接并完成传输。独立回环网络内顺序执行，耗时 152.596 秒，用户 / 内核态 CPU 4.099 / 2.301 秒，峰值 RSS 11928 KiB。607 个文件描述符采样的峰值为 17，末次为 14，没有随循环增长。此为回收稳定性验证，不是公网吞吐量基准。

Clippy 全目标警告检查、Rust 格式、TypeScript 与前端构建通过。amd64 主控及 Agent 已运行验证；arm64 交叉编译与 ELF 检查，未声明 ARM 硬件实测。

## 安全与主控

开发站测试覆盖私有文件和目录遍历、Host、请求体 / 头 / URI 限制、未登录权限、密码限速、未认证 / 跨来源 WSS 和慢请求头。200 并发客户端完成 600 次请求，耗时 1.76 秒，其中 200 为 128 次、429 为 472 次，P95 为 1474.82 ms，没有 HTTP 5xx 或进程失败；限流响应不计为业务吞吐。

本次不添加依赖，保留 0.3.7 同日审计中的 RUSTSEC-2023-0071（rsa 0.9.10、0.10.0-rc.18），见 [SECURITY.md](../SECURITY.md)。源码与最终解压发行包扫描不含泄露凭据，全部文件 SHA-256、归档路径和 Ed25519 下载签名经过验证。不宣称测试可以证明不存在所有漏洞。

0.3.7 的生产连接回收、12 组监听、5 分钟资源观察以及测试主控断线重连记录保留在 [上版验收](验收-0.3.7.md)；0.3.8 延续该回收逻辑并补齐持续单向传输。目标服务拒绝连接、上游超时或协议认证问题需要分别诊断，不能用端口监听成功替代应用连通性检查。

安装方式不变。详见 [长连接与空闲回收](长连接与空闲回收.md)。
