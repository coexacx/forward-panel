# 0.3.7 验收记录

日期：2026-10-10。代码、构建和主动故障模拟在开发服务器及独立测试节点执行；生产执行连接元数据诊断、备份、受控更新和真实状态核验。结果不代表不存在其他漏洞或所有网络环境均已覆盖。

## EOF 原因与回归

现场确认旧 Agent 的 294 条转发连接已关闭，对应 588 个 TCP_CLOSE socket，其中 294 个仍返回非零发送队列计数。旧逻辑一直等待这些计数清零，导致 socket、逻辑内存预算及连接额度滞留，新的 TCP 请求在握手后被关闭。

新增回归测试分别覆盖客户端和目标端在正常半关闭之后、还有数据待确认时发送复位。旧代码在客户端场景第一次循环就未能释放连接；新代码两端场景均通过。保留慢速读端、半关闭、原有数据及计量校验。

单侧 EOF 后复位、另一端不关闭的路径也已复现并修复；补丁前首例未能及时归零。覆盖客户端和目标端，以及发送队列为空 / 非空的四种组合。只有出现半关闭后才启动终止状态检查，不为正常双向数据复制增加定时轮询。

12 条规则同时运行、共享两份各 6 个 TCP 和 UDP 额度的套餐，完成 384 次正常关闭与复位混合循环；逐条检查计数和套餐额度，并验证 UDP 空闲、删除部分规则、暂停及同端口复用。

## 连续故障模拟

两个场景各执行 1,000 轮，共 2,000 轮真实 TCP 连接。每个测试内核的 TCP 容量限制为 2，逐轮校验转发连接数和租约连接数归零，再新建连接；结束后再验证正常完整传输，避免通过提高连接上限掩盖滞留。

在仅回环网卡的独立网络命名空间中以普通编译账户顺序执行两组测试，耗时 152.915 秒，用户态 CPU 3.719 秒、内核态 CPU 2.213 秒，测试进程峰值 RSS 12252 KiB。独立采样得到 608 个文件描述符快照，峰值 17，末次 17，没有随循环持续增长。首次在共享网络环境并行启动时，目标端用例的规则初始化断言失败，尚未进入循环；为排除共享网络及临时端口干扰，改在独立回环环境顺序执行，两组均通过。此为回收稳定性测试，不是公网带宽或长期整机吞吐基准。

原有跨节点限额、流量上报去重、用量调整、达量暂停、计费周期、规则迁移及权限测试继续通过。Clippy 全目标警告检查、Rust 格式、TypeScript 和前端构建通过。

## 安全

人工审阅 TCP_INFO 查询的文件描述符生命周期、结构体尺寸、内核返回长度和错误退出路径；结束后队列检查与单侧 EOF 后的异常观察均被限制在当前连接生命周期内，不在正常双向业务数据复制期间增加轮询。SO_ERROR 仅在 TCP_CLOSE 后读取，避免误处理临时软网络错误。不增加依赖、系统权限，不改变防火墙、路由或主控与 Agent 的认证。

npm 审计未发现已知漏洞。RustSec 数据库提交 7eebec69c352c7191b1f13eb95dd510eeca5d1de，仍保留 RUSTSEC-2023-0071，涉及 rsa 0.9.10 与 0.10.0-rc.18；详见 [SECURITY.md](../SECURITY.md)，不宣称零告警。源码和解压发行包执行凭据扫描；归档路径、全部文件 SHA-256、amd64/arm64 架构与 Ed25519 下载签名验证通过。

安装和反向代理方式不变。修复说明见 [连接回收与 EOF 修复](连接回收与EOF修复.md)，多网卡说明及历史验收记录继续保留。
