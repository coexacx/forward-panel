# 0.3.3 验收记录

日期：2026-10-09。开发、编译、安全检查与真实转发测试在开发服务器和独立测试被控完成；生产升级另做备份及只读回归。本记录限定于已执行的测试，不代表不存在漏洞。

## 连接统计

- 16 项 Rust 测试通过：8 项单元测试、4 项 MariaDB / 业务集成测试、4 项真实回环网络测试。格式检查、Clippy 全目标检查、TypeScript 检查和前端构建通过。
- 真实测试被控运行新版 WSS Agent。两名测试用户共用同一节点，三条规则分别建立不同数量的 TCP 连接与 UDP 会话，用户端和管理员端均显示对应数量。
- 128 条并发 TCP 连接分布在两条规则上，分别显示 64；全部关闭后归零。相同 UDP 来源连续发送多个包不重复计数，连续 30 秒无流量后会话归零。
- 验证 TCP 失败拨号、半关闭、正常关闭、任务取消、规则删除、目标修改、周期更新和不相关规则增删；周期更新保留仍在工作的连接统计。目标 TCP 探测不计入业务连接。
- 真实停止测试 Agent 后，规则显示离线、连接数返回未知；恢复后规则重新监听并恢复上报。
- 用户只能取得自己的规则统计；共享节点探针不含其他租户的规则编号或原始统计。数据库测试覆盖伪造其他节点规则、重复序号、超限数量、负数、无效编号、超过 512 条上报，以及旧版 Agent 缺少统计的兼容行为。
- 浏览器检查桌面和手机共 40 个页面，没有脚本异常、HTTP 5xx 或整页横向溢出。两端转发表格自动刷新、浅色/深色显示通过；模拟浏览器状态请求中断后，超过时效的数字显示「—」，请求恢复后重新显示实时值。
- TCP 是已成功连接目标的转发连接，UDP 是当前客户端来源会话。上报每秒一次，页面约 3 秒刷新；两者都不是历史累计次数。详见[连接统计说明](连接统计.md)。

## 安全与负载

私有文件路径、路径穿越、Host、请求体/请求头/URI 大小边界、匿名越权、登录限速、WSS 认证及跨站拒绝、慢请求头超时检查均通过。人工审阅新增统计的资源归属、报告重放处理、任务取消回收、数据隔离和失效显示。

200 个并发客户端请求管理状态接口 600 次，耗时 1.968 秒：HTTP 200 为 132 次、HTTP 429 为 468 次，没有 HTTP 5xx 或进程崩溃。P95 为 1585.81 毫秒。限流响应包含在请求总量中，不作为成功业务吞吐成绩；同时存在编译负载，不是独占硬件基准。

npm 审计 0 项已知漏洞；源码凭据扫描 0 项泄漏。RustSec 数据库提交 550efd3d587a29b2e2c2b21b17a440da4fede999，仍有 RUSTSEC-2023-0071，涉及 rsa 0.9.10 与 0.10.0-rc.18；本次未新增依赖告警。[上游公告](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)仍无修复版本，使用路径与限制见 [SECURITY.md](../SECURITY.md)。

## 发布范围

提供 amd64 / arm64 静态主控与 Agent。实机验收使用 amd64，arm64 仅交叉编译、ELF 架构与发行完整性检查，未进行独立硬件验收。发行流程检查所有文件 SHA-256、主控及 Agent 清单 Ed25519 签名、包路径和解压后凭据泄漏；真实配置、密钥与验收凭据不进入源码包。

升级不改变数据库结构、套餐限额、端口池、计费规则或 Nginx 配置。连接计数仅在建立及关闭时变化，逐包转发路径没有新增统计操作。本次没有重复进行吞吐基准或长期稳定性测试；之前的吞吐及套餐跨节点限额记录见 [0.3.2 验收](验收-0.3.2.md)。支付和邮件代码未修改，没有向真实商户付款或给真实用户发送测试邮件。
