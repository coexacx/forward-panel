# 0.3.6 验收记录

日期：2026-10-10。代码、构建与主动压力测试在开发服务器及独立测试节点完成；生产仅执行备份、受控升级、监听检查和少量连接验证。以下记录只代表已执行的检查。

## 多网卡修复

旧部署器把默认路由的首选源地址同时用作规则监听地址，导致第二网卡上的连接无法进入 Agent。现在默认监听所有 IPv4 地址。UDP 使用目的地址信息选择回包源地址，并按客户端与本机地址区分会话。

在 Debian 测试节点建立独立网络命名空间，两张虚拟网卡分别拥有不同子网地址，以 Agent 普通服务账户运行静态 musl 测试程序。完成：

- 两张网卡的 TCP 建连、双向数据与 UDP 回显。
- 同一个客户端端口同时访问两张网卡，回复源 IP 正确；已连接 UDP socket 能收到第二网卡响应。
- 连续配置刷新保留既有 TCP 连接；冲突规则绑定失败不影响原连接。
- TCP / UDP 会话计数与上传、下载累计字节数精确一致。
- 测试完成删除网络命名空间，不更改测试节点现有接口、路由、防火墙或其他应用。

生产升级后，现有 12 组 TCP+UDP 规则均实际监听 0.0.0.0，两张网卡共 24 次 TCP 入口连接检查全部成功。被控 WSS 上报 0.3.6，无配置错误。被动 TCP 标志采样看到第二网卡的真实连接完成握手并产生数据往返。未将此描述为全部用户协议或上游链路已经验收。

## 安全与请求压力

私有路径、路径穿越、Host 校验、请求体/头/URI 上限、匿名管理接口拒绝、登录限速、未认证 WSS、跨站请求及慢请求头超时检查通过。

200 个并发客户端执行 600 次管理请求，耗时 1.609 秒：128 次正常返回、472 次触发 429 限流，P95 1386.78 ms，无 5xx 或进程崩溃。限流响应不算业务吞吐。

人工审阅 UDP recvmsg / sendmsg 的指针生命周期、栈缓冲对齐、控制消息长度、glibc 与 musl ABI 差异，以及通配端口冲突和升级事务。没有增加依赖或 Agent 权限。

npm 审计 0 项已知漏洞。RustSec 数据库提交 7eebec69c352c7191b1f13eb95dd510eeca5d1de，保留既有 RUSTSEC-2023-0071，涉及 rsa 0.9.10 和 0.10.0-rc.18；实际使用路径见 [SECURITY.md](../SECURITY.md)，不宣称零告警或不存在漏洞。源码及解压发行包检查凭据泄漏；文件 SHA-256、归档边界及 Ed25519 下载签名均验证。
