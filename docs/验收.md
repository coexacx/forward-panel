# 0.3.1 验收记录

验证日期：2026-10-09。开发、构建与测试在开发环境完成；生产更新另做备份与回归检查。记录描述已执行范围，不代表不存在任何漏洞。

## 功能与协议

- 10 个 Rust 测试通过：4 个单元测试、MariaDB 兼容、租约生命周期、规则迁移各 1 个集成测试、3 个真实网络测试。Clippy 全目标无警告，格式与前端构建通过。
- 测试套餐普通编辑、可选强制同步、删除商品保留付费租约、管理员删除租约、用户删除结束/到期租约、其他用户越权拒绝、迟到流量与重复支付回调。
- 在真实测试节点验证 TCP、UDP、占用端口时的失败提示；保持 TCP 长连接，同时新增、修改和释放其他规则，原连接与“已监听”状态保持。
- 配置增量帧测试新增、修改、删除、空心跳、丢失基线拒绝、重连全量同步、旧版兼容和 512 规则上限。
- 使用官方 AnyTLS 参考服务与 Mihomo 客户端，连续完成 6 次 1 MiB 内容一致性传输；旧版 0.3.0 同样通过基线测试。此项不使用真实客户节点凭据。
- 测试保存 SSH 密码后数据库不含明文、状态接口不返回明文/密文；空密码只复用原节点及原连接目标，变更目标要求重新填写。
- 模拟保存的 SSH 指纹变化：未确认时拒绝认证，确认具体新指纹后连接成功；不修改服务器实际 SSH 主机密钥。
- 真实执行签名 0.3.0 → 0.3.1 Agent 更新，确认新版上报、成功任务自动清理及最新版更新按钮禁用。
- 在测试服务器运行第二个隔离 Agent 实例，验证同节点恢复、跨节点迁移、用户端节点/入口/备注同步、旧节点删除后的文件恢复。保留暂停和流量状态，未修改服务器操作系统。
- 迁移测试覆盖端口占用变化重新预览、规则重复导入拒绝、文件修改拒绝、非管理员拒绝、原/新节点累计流量去重与保留。
- 浏览器检查 40 个桌面及手机页面，无脚本异常、HTTP 5xx 或横向溢出；实际操作套餐编辑、强制同步、商品删除与用户删除结束租约，并查看新增连接、更新、导入/导出表单。
- amd64 与 arm64 静态发行二进制构建；真实节点运行使用 amd64，arm64 未在独立硬件上进行验收。

## 安全与负载

私有路径、路径穿越、Host 限制、请求体/头部/URI 大小、匿名越权、登录限速、WSS 认证和跨站拒绝、慢请求头超时均通过检查。新接口另检查管理员身份、CSRF、SSH 凭据绑定、导出签名和预览凭证。

200 个并发客户端向管理状态接口发起 600 次请求，1.500 秒完成：128 次 HTTP 200、472 次 HTTP 429，无 HTTP 5xx 或崩溃；P95 为 1305.39 毫秒。约 400 次/秒包含限流拒绝响应，不是成功业务吞吐量。测试发生在同机进行发行构建时，不能用于独占硬件基准比较。

npm 全依赖审计为 0 项已知漏洞，Gitleaks 源码检查为 0 项凭据泄漏。RustSec 最新数据库仍报告 RUSTSEC-2023-0071，两处依赖版本为 rsa 0.9.10 与 0.10.0-rc.18；当前使用路径及限制见 SECURITY.md。这是保留的已知依赖告警，不宣称零漏洞。

原版完整业务与性能记录见[0.3.0 验收记录](验收-0.3.0.md)。支付、邮件及未改动功能沿用该验收，本次没有向真实商户付款或向真实用户发送测试邮件。

发行包逐文件验证 805 项 SHA-256，并验证主控发行清单与 Agent 清单的 Ed25519 签名。解压包 Gitleaks 初报 4 项，均位于已逐文件核对的 SHA256SUMS.json 校验和；仅排除该校验和文件后扫描为 0 项。未排除源文件或运行凭据。
