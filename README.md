# Vistart 转发面板

Rust 主控与转发 Agent，MariaDB 保存业务数据。前端编译进主控二进制，运行时不需要 PHP、Node.js 或 Rust 工具链。

用户在套餐额度内选择节点、申请端口并设置转发目标；管理员管理服务器、端口池、套餐、订单、支付及邮件。

## 安装

以 root 在新服务器上运行：

~~~bash
curl -fL https://github.com/coexacx/forward-panel/releases/latest/download/install.sh -o /tmp/forward-panel-install.sh
bash /tmp/forward-panel-install.sh
~~~

只需填写站点名称。脚本安装运行环境和 MariaDB，生成管理员密码，启动服务并显示 http://服务器IP:19280。初始凭据仅保存在 root 可读文件中。

脚本不配置 Nginx、不申请证书。正式使用前按照[反向代理文档](docs/反向代理.md)配置 HTTPS，然后在 forward-panel 菜单中设置面板地址。节点使用 WSS，必须配置有效 HTTPS 才能添加。

## 业务规则

- 套餐带宽、TCP 连接、UDP 会话按已购租约跨节点合计执行；强制同步已有租约必须先预览影响并确认。详见[套餐限额与变更预览](docs/套餐限额与变更预览.md)。

- 规则增量同步：新增、编辑、释放仅下发对应变更。每条规则独立确认监听状态；WSS 重连时全量校对，旧 Agent 保持兼容。
- 套餐商品支持编辑、删除及可选强制同步已有租约；管理员可删除用户租约，用户可删除自己的结束或到期租约。
- SSH 连接信息与 Agent 更新独立管理；密码使用 AES-256-GCM 加密保存。签名版本检查发现新版后才允许更新，成功任务自动清理。
- 支持同面板内规则导出、导入预览、跨节点迁移及服务器重装恢复；用户端自动显示新节点与入口地址。详见[服务器维护与规则迁移](docs/服务器维护与规则迁移.md)。
- 每个分配端口同时提供 TCP 与 UDP，合计占一个端口额度。用户申请时随机分配，或指定池内尚未占用的端口。
- 一个租约的端口额度在其绑定的多台转发服务器间共同计算。不同租约的流量与端口额度独立。
- Agent 汇报持久化累计流量；主控按规则、计费周期和报告序号去重。达到该租约流量限额后暂停其所有节点上的规则。
- 续费仅延长到期日；付费重置仅开启新的流量周期；按原自然周期自动重置。
- 支持域名目标、DDNS 重解析、多个目标负载均衡及目标 TCP 延迟检查。
- 主控不承担业务转发。新增节点通过 SSH 检查系统、验证签名并部署预编译 Agent；节点目前支持 Debian/Ubuntu 的 amd64、arm64。
- 在线删除节点会撤销规则、结算最后一次流量并清除 Agent 私有配置。离线删除会撤销面板记录与凭据；不会操作服务器上的其他应用。
- 管理员和普通用户共用登录入口。仅管理员显示后台入口；管理员仍可正常购买和使用套餐。
- 邮件验证码、真实密码校验、二步验证、恢复码、易支付 V1/V2、多支付方式与订单状态管理。

## 部署边界

主控二进制支持 Linux amd64/arm64，安装器适配常见 systemd 发行版。MariaDB 通过本地连接运行。Nginx 负责公网 HTTPS 与 WSS，主控 HTTPS 模式只监听回环地址。

HTTP 的 IP:端口入口适合首次部署检查；HTTP 不加密，正式登录和节点管理应使用 HTTPS。主控与节点之间不接受明文 WS。

下载从 GitHub Releases 获取；安装器与远程部署器校验 Ed25519 签名、SHA-256 和文件大小。签名私钥不在仓库中。

每条规则支持实时 TCP / UDP 连接统计，见[连接统计说明](docs/连接统计.md)。

Agent 按节点资源为 TCP / UDP 缓冲预留容量，避免高缓冲配置触发服务内存上限。见 [Agent 资源保护](docs/Agent资源保护.md)。

管理员可在用户套餐管理中调整本期已用流量，随后继续累计并执行跨节点额度。见 [已用流量调整](docs/已用流量调整.md)。
